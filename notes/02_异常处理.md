# 异常处理

本篇合并原 `异常处理.md` 与 `未命名.md` 中的错误处理条目。

## 常见的内置异常类型

| 异常 | 说明 |
| --- | --- |
| `ZeroDivisionError` | 当除数为 0 时引发的错误 |
| `FileNotFoundError` | 文件不存在 |
| `IndexError` | 索引超出范围引发的错误 |
| `KeyError` | 字典取值时 key 不存在的异常 |
| `NameError` | 使用没有声明的变量时引发的异常 |
| `TypeError` | 类型不合适引发的错误（原笔记写作 `typeError`） |
| `ValueError` | 传入的值错误 |
| `AttributeError` | 属性或方法不存在的异常 |
| `IndentationError` | 不正确的缩进引发的错误 |
| `SyntaxError` | Python 中的语法错误 |

## 异常捕捉流程

```python
try:
    # 可能出错的代码
    pass
except:
    # 异常发生时的代码
    pass
else:
    # try 正常运行时进行的
    pass
finally:
    # 无论 try 是否运行都执行
    pass

try:
    # 可能出错的代码
    pass
except ZeroDivisionError:
    pass
except ValueError:
    pass

try:
    pass
except (ZeroDivisionError, ValueError) as e:
    pass
```

### try-except-else-finally 结构（草稿条目）

```python
try:
    正常语句
except 异常名称:   # 原笔记写作 expect（应为 except）
    发生异常执行
else:
    未发生异常执行
finally:
    不论是否异常均执行
```

## 异常抛出

```python
raise 异常类型("错误信息描述")
```

异常自主命名（`raise` 语句）：

```python
raise Exception(自主名称)
```

示例（原草稿）：

```python
try:
    a = input('请输入你的性别：')
    if a != '男' or a != '女':
        raise Exception('输入错误')
    else:
        pass
except Exception as e:
    print(e)
finally:
    print('输入正确')
```

## 自定义异常

```python
class ValidationError(Exception):
    def __init__(self, field, message, error_code=None):
        self.field = field
        self.error_code = error_code
        super().__init__(f"{field}: {message}")

def register_user(username, email):
    if len(username) < 3:
        raise ValidationError("username", "长度至少3个字符", error_code=1001)
    if "@" not in email:
        raise ValidationError("email", "邮箱格式不正确", error_code=1002)

try:
    register_user("ab", "test")
except ValidationError as e:
    print(f"字段 '{e.field}' 错误: {e} (错误码: {e.error_code})")
    # 可以向前端返回更结构化的错误信息
```
