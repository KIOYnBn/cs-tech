# 字符串与格式化

本篇整理自原 `未命名.md` 草稿中与字符串、格式化、类型转换、转义、校验、编解码相关的全部条目。

## 数据类型格式化输出

### 格式化类型

| 格式符 | 含义 |
| --- | --- |
| `%c` | 字符 |
| `%s` | 字符串 |
| `%d` | 十进制整数 |
| `%u` | 无符号整型 |
| `%o` | 八进制 |
| `%x` / `%X` | 十六进制 |
| `%f` | 浮点数，确定小数点后位数用 `%.nf` |
| `%e` / `%E` | 科学计数法格式化浮点数 |
| `%g` / `%G` | `%f` 和 `%e` 的简写 |
| `%p` | 用十六进制格式化变量地址 |

### 结构格式化操作

- 引导符号及填充符号：`' : '`
- 对齐：`<`（左对齐）、`>`（右对齐）、`^`（居中）
- `"d"`：表示格式化为整数
- 宽度：`10`
- 千位分隔符：`','`
- 精度
- 格式化类型
- `0, 1, 2`：表示 `format` 中的第几个变量，从零计

示例：

```python
{0>2d}   # 右填充 0，宽度为 2
{:,}     # 千位分隔符
{:.2f}   # 保留两位小数
{:10d}   # 右对齐，宽度为 10
{:o}     # 八进制
```

`format` 输出示例：

```python
print("姓名：{0},年龄：{1}，成绩：{2},姓名及年龄：{0}{1}".format(name, age, score))
```

## 数据类型转换

| 函数 | 作用 |
| --- | --- |
| `int(x)` | 整数 |
| `float(X)` | 浮点数 |
| `str` | 字符串 |
| `chr` | 整数转为字符 |
| `ord` | 输出字符的 unicode 值 |
| `hex` | 十六进制字符串 |
| `oct` | 八进制字符串 |
| `bin` | 二进制字符串 |
| `eval` | 去掉字符串外侧引号，使其变成自适应数据类型 |

`eval` 示例：

```python
age = '3.2+1'
print(type(eval(age)))  # float
```

## 逃逸字符（转义字符）

| 转义 | 含义 |
| --- | --- |
| `\b` | 回退一格 |
| `\"` | 双引号 |
| `\t` | 制表符 |
| `\'` | 单引号 |
| `\n` | 换行 |
| `\\` | 斜杠 |
| `\r` | 回车 |

### 原始字符串（r）

`r` 将逃逸字符变为普通字符：

```python
s = r'lang\tver\npython\t3'
print(s)  # lang\tver\npython\t3
```

## 字符串操作

| 方法 | 作用 |
| --- | --- |
| `str.lower()` | 全部转成小写字母 |
| `str.upper()` | 全部转成大写字母 |
| `str.split(sep=None)` | 以 sep 指定的分隔符切割，输出列表 |
| `str.count(x)` | 计算 x 出现的次数 |
| `str.find(x)` | 判断 x 是否存在 |
| `str.index(x)` | x 的位置 |
| `str.startswith(s)` | 是否以 x 开头 |
| `str.endswith(x)` | 是否以 x 结尾 |
| `str.replace(old, news)` | 替换 |
| `str.center(width, fillchar)` | 字符串位于中心，整体宽度为 width，填充字符为 fillchar |
| `str.join(x)` | 加入 x 字符串 |
| `str.strip(x)` | 去掉 x 字符串 |
| `str.lstrip(x)` | 去掉 str 中左侧的 x 字符串 |
| `str.rstrip(x)` | 去掉 str 中右侧的 x 字符串 |

### 字符串连接与重复

```python
a = 'H'
b = 'o'
a + b          # 'Ho'
a * n          # 重复输出字符串 n 次，如 'H' * 3 = 'HHH'
```

### 截取与切片

```python
a = 'Hellow'
a[0]      # 'H'
a[1:3]    # 'el'
```

切片格式：

```python
str[切片起始位:切片中止位:切片步数]
```

### 其他

```python
a = 'hellow world'
print(len(a))   # 查询字符个数：12
x in s          # x 是否位于 s 中
x not in s
max(s)
min(s)
```

## 搭配函数

### enumerate（枚举函数）

常用于 for 循环遍历：

```python
a = 'abcd'
for i, j in enumerate(a):
    print(i, j)
```

输出结果：

```
0 a
1 b
2 c
3 d
```

### join（连接成字符串）

格式：`''.join(list/set/tuple)`，输出为字符串。

## 数据验证

常见的数据验证类型（返回类型为布尔类型）：

| 方法 | 作用 |
| --- | --- |
| `str.isdigit()` | 所有字符都是阿拉伯数字 |
| `str.isnumeric()` | 所有字符都是数字 |
| `str.isalpha()` | 原笔记写作「所有字符都是数字」（按 Python 实际语义应为「所有字符都是字母」，此处保留原文） |
| `str.isalnum()` | 所有字符都是数字或字母 |
| `str.islower()` | 所有字符都是小写 |
| `str.isupper()` | 所有字母都是大写 |
| `str.istitle()` | 所有字符都是首字母大写 |
| `str.isspace()` | 所有字符都是空白字符 |

## 字符串的编码和解码

### 编码 encode()

```python
str.encode(encoding='UTF-8', error='strict/ignore/replace')
```

### 解码 decode()

```python
str.decode(encoding='UTF-8', errors='strict/ignore/replace')
```
