# 标准 IO 与解析

## scanf_s

- 从 `stdin` 解析内容。
- 格式：`scanf_s(解析格式，赋值变量)`。
- **注意**：输入字符串时需要标注缓存区大小，其他变量不需要。

```c
#include <stdio.h>

int main(void) {

	char str[50] = { 0 };
	scanf_s("%49s", str, (unsigned int)sizeof(str));
	puts(str);

	int num;
	int result = scanf_s("%d", &num);
	if (result == 1) {
		printf("This number is %d\n", num);
	}
	else if (result == EOF) {
		puts("Reaching end");
	}
	else {
		puts("input a invalid number");
	}

	char ch;
	scanf_s(" %c", &ch, 1);
	printf("This char is %c", ch);

	return 0;
}
```

读取整数的基础用法：

```c
#include <stdio.h>
int main(void) {
	int input_number;
	printf("请输入一个整数\n");
	scanf_s("%d", &input_number);
	printf("您输入的整数为%d\n", input_number);
	return 0;
}
```

## fgets

- 格式：`fgets(赋值变量, 缓冲区大小, 输入流)`。

```c
#include<stdio.h>
int main(void) {
	char buffer[50];
	int num1;

	fgets(buffer, sizeof(buffer), stdin);
	sscanf_s(buffer, "%d", &num1);

	return 0;
}
```

## sscanf_s

- 作用：从内存字符串中解析。
- 格式：`sscanf_s(解析字符串, 解析格式, 赋值变量)`。
- 与 `fgets` 组合使用可避免 `scanf` 残留换行符的问题（示例同上）。

## 注意事项

1. `scanf` 无法处理 `char` 变量，可以先处理 `int` 变量，然后使 `char` 定义的变量等于 `int` 定义的变量。
2. 输入或输出字符串时，可以在 `%` 和 `s` 之间输入数字，表示要输入或输出的字符串长度（如 `%49s`）。
