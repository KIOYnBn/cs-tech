# 环境变量

- 读写环境变量。
- **注意**：谨慎写入环境变量。

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {

	const char* str = getenv("PATH");
	if (str == NULL) {
		fprintf(stderr, "getenv failed\n");
		return 1;
	}

	puts(str);
	errno_t err = _putenv_s("My_test", "Hello");

	return 0;
}
```
