# 常用术语与编程惯例

> 这一页汇总零散的编程惯用法与缩写约定，便于快速查阅；具体函数用法见对应主题笔记。

| 术语 / 写法 | 含义 |
| --- | --- |
| `srand()` | 初始化随机数种子（声明于 `stdlib.h`），常配合 `rand()` 使用 |
| `isPrime` | 自定义函数，常用于判断一个数是否为素数：`int isPrime(int n)`，素数返回 1，否则返回 0 |
| `cnt` | 常用作计数器变量名，统计程序中事件次数或对象个数 |
| `malloc` | 指针获取内存（动态申请） |
| `free` | 指针归还内存（动态释放） |
| `putchar` | 输出一个字符 |
| `getchar` | 输入一个字符 |

> **注意**：原笔记曾写成「putchar 输入一个字符 / getchar 输出一个字符」，两者方向写反了；正确用法是 `putchar` 输出、`getchar` 输入。

## 相关内存函数

- `malloc`：申请指定字节数的堆内存，返回 `void*`。
- `realloc`：重新调整已分配内存块的大小。
- `free`：释放已分配的内存。

详细对比与示例见 [栈内存与堆内存](03-变量与内存-栈内存与堆内存.md)。

- `stdlib.h`：提供 `srand` 等函数。
