# 数据类型

## 标量类型

1. 数值：`int`、`float`、`complex`、`bool`
2. `str`
3. `NoneType`

### 复数（complex）

```python
a = 12 + 23j  # 原笔记写作 a = 12 + 23j(i)
```

输出实部与虚部：

```python
print("实数部分", a.real)
print("虚数部分", a.imag)
```

### 布尔类型（bool）

- `0` 或空字符串的 bool 值为 `False`。
- 非 `0` 或非空字符串的 bool 值为 `True`。

## 容器类型

### list（列表）

- 添加
  - 末尾添加：`append`
  - 指定位置添加：`insert`
  - 批量添加：`extend`
- 删除
  - 按索引：`del`
  - 按值：`remove`
  - 删除并返回：`pop`
- 长度：`len`
- 排序：`sort`
- 反转：`reverse`
- 统计次数：`count`

### tuple（元组）

- 长度：`len`
- 统计：`count`
- 索引：`index`

### dict（字典）

- 取值：`get`
- 删除：`del`
- 删除并范围（返回）：`pop`
- 删除最后的键值对：`popitem`

### set（集合）

- 添加：`add`
- 批量添加：`update`
- 删除：`remove` / `discard`
- 随机删除：`pop`
- 运算
  - `&`：交集
  - `|`：并集
  - `-`：差集
  - `^`：对称差集（原笔记称「补集」）

## 数据类型查看

使用 `type(variable)`：

```python
a = 10
print(type(a))
```

## 进制定义

- `print` 默认按十进制输出。
- 二进制：`0b` / `0B`
- 八进制：`0o` / `0O`
- 十六进制：`0x` / `0X`

## 解包赋值

```python
a, b, c = (1, 2, 3)
# a = 1, b = 2, c = 3
```
