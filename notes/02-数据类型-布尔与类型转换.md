# 布尔与类型转换

## 布尔类型

值只有 `true`、`false`（使用 `bool` 需包含相应头文件）。

```c
#include <stdio.h>
int main(void) {
	bool a = true;
	return 0;
}
```

## 自动类型转换

![自动类型转换与printf提升](attachments/自动类型转换与printf提升.jpg)

- 对于 `printf`，任何小于 `int` 的类型会被转换成 `int`；`float` 会被转换成 `double`。
- 但是 `scanf` 不会这样处理：要输入 `short`，需要使用 `%hd`。

## 显式类型转换

- 类型转换时要注意大小不要超范围。

```c
#include <stdio.h>
#include <stdint.h>
int main(void) {
	int32_t intNum = 288;
	int16_t shortNum = (int16_t)intNum;
	return 0;
}
```

## 整数溢出

- 在 C 语言中，整数是有上界的；当整数过大时会变成负数。
- 此时可将 `int` 改为 `double` 解决问题——`double` 定义下数的范围更大。
