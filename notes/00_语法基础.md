# Python 语法基础

本篇整理自原 `未命名.md` 草稿中的入门条目，涵盖打印、注释、命名规范、关键字、内存地址、数值精度、制表位等基础约定。

## 打印输出

`print` 的基本形式：

```python
print(value, sep='', end='', file=)
```

- `sep`：多个值之间的分隔符，默认为空格（原笔记写作空串）。
- `end`：输出结尾字符，默认为换行。
- `file`：输出目标文件。
- 也可使用格式化输出：`print("" % ())`。

> 注：原笔记中 `print(value, sep='', end='', file=)` 的默认值与 Python 实际默认值（`sep=' '`、`end='\n'`）存在差异，此处保留原文写法，供人工复核。

- 单行注释：`#`
- 多行注释：原笔记中该项为空，未记录具体写法（通常是三引号字符串 `'''...'''` 或 `"""..."""`）。

## 中文声明注释（coding）

```python
#coding = UTF-8
```

## 变量命名规范

- 常量：全字母大写。
- 变量：不能用数字开头，字母尽量小写。

## 查询关键字（keyword）

```python
import keyword
print(keyword.kwlist)
```

## 查询内存地址（id）


## 减少小数个数（round）

```python
round(number, 小数位数)  # 如 round(x, 3)
```

- 注意：`round` 只能减少小数个数，不能增加。
