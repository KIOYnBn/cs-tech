# 整数与进制

## 整数类型

- 工程中通常使用 `stdint.h` 的 `int8_t`、`int16_t`、`int32_t`、`int64_t`，而不用 `short`、`int`、`long`。
- `int32` 之后的字面量：`uint32` 需要加 `U`，`long` 类型加 `L`。
- 格式化输出通常使用 `inttypes.h` 的 `PRId8`、`PRId16` 等，而不是 `%d`。

**整数常量写法**：

- 十进制：数字 `0~9` 开头。
- 八进制：数字 `0` 开头。
- 十六进制：数字 `0x` 开头，不区分字母大小写。

**后缀**：

| 后缀 | 含义 |
| --- | --- |
| `u` | unsigned |
| `l` | long |
| `ll` | long long |

```c
#include <stdio.h>

int main() {
	int dec_int = 28;
	short s_int = 28;
	int oct_int = 027;
	int x_int = 0x2A;
	unsigned dec_uint = 28u;
	long dec_long = 28l;
	long long dec_llong = 28ll;
	unsigned long long dec_ullong = 28ull;
	printf("i: %d, h:%hd, o: %#o, x: %#x, u: %u, l: %ld, ll: %lld, ull:%llu", dec_int, s_int, oct_int, x_int, dec_uint, dec_long, dec_llong, dec_ullong);
	return 0;
}
```

## 进制表示与输出

| 进制 | 表示方式 | 输入格式 | 输出格式 |
| --- | --- | --- | --- |
| 十进制 | 正常表示习惯 | `%d` | `%d` |
| 八进制 | 数前面有一个零，例：`012` | `%o` | `%o` |
| 十六进制 | 数前面有 `0x`，例：`0x12` | `%x` | `%x` |

- 前缀 `o` 表示八进制，`x` 表示十六进制（字母分大小写）。
- `%#` 形式的格式符可显示进制前缀（如 `%#o`、`%#x`）；原笔记亦记为「`%` 能显示进制」。
- 八进制字面量初始化字符变量、十六进制字面量初始化整型变量，用 `%d` 输出时会按十进制显示：

![八进制十六进制字面量示例](attachments/八进制十六进制字面量示例.png)

- 使用 `%o`、`%x` 输出时保留进制前缀：

![八进制十六进制输出格式示例](attachments/八进制十六进制输出格式示例.png)

对应代码：

```c
int main(void) {
	char c = 012;
	int i = 0x12;
	printf("c=%d, i=%d\n", c, i);   // c=10, i=18
	return 0;
}
```

```c
int main(void) {
	char c = 012;
	int i = 0x12;
	printf("c=0%o, i=0x%x\n", c, i); // c=012, i=0x12
	return 0;
}
```

## 整数的输入输出

1. 范围小于等于 `int` 的都可以用 `%d` 输出。
2. 范围大于 `int` 的都可以用 `%ld` 输出。
3. 用二进制（无符号）方式计算的用 `%u` 表示。
4. 用 `unsigned long` 定义的，可以用 `%lu` 输出。
