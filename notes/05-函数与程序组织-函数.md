# 函数

一个函数尽量只做一件事。

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int32_t add(int32_t num1, int32_tnum2);

int main(void) {

	int32_t num1;
	int32_t num2;

	puts("please input two number");
	scanf_s("%d, %d", num1, num2);
	printf(
	"the sum of %" PRId32 " and %" PRId32 " is %" PRId32"",
	num1,
	num2,
	add(num1, num2));

	printf(")

	retur 0;

}

int32_t add(int32_t num1, int32_t num2) {
	return num1 + num2;

}
```

> **注意**：以上代码按原笔记保留，其中包含笔误（`retur 0`、`scanf_s` 参数缺少 `&` 等），使用时需自行修正。

## 卫语句

- 核心思想：在函数 / 代码块的开头，提前检查异常 / 边界条件，一旦满足就立即返回 / 退出，避免嵌套的条件判断。
- 通常用于简化 `if` 逻辑判断。

常规 `if` 示例：

```c
// 计算两个正整数的和（仅当 num1、num2 都 > 0 时有效）
int add_positive(int num1, int num2) {
	int result = 0;
	if (num1 > 0) {
		// 第一层嵌套
		if (num2 > 0) {
			// 第二层嵌套
			result = num1 + num2;
		}
		else {
			printf("num2必须是正数！\n");
		}
	}
	else {
		printf("num1必须是正数！\n");
	}
	return result;
}
```

卫语句示例：

```c
int add_positive(int num1, int num2) {
	// 卫语句1：检查 num1，不满足则直接返回
	if (num1 <= 0) {
		printf("num1必须是正数！\n");
		return 0; // 异常返回值（也可返回 -1 / EXIT_FAILURE 等）
	}
	// 卫语句2：检查 num2，不满足则直接返回
	if (num2 <= 0) {
		printf("num2必须是正数！\n");
		return 0;
	}
	// 所有异常条件都被“守卫”挡掉，剩下的就是正常逻辑
	return num1 + num2;
}
```

## 递归

- 类型：
  - 普通递归：`return` 后还有行为操作。
  - 尾递归：`return` 后没有行为操作。示例：阶乘。
- 本质：函数嵌套。

## 可变参数

```c
#include <stdio.h>
#include <stdarg.h>

int sum(int arg_count, ...) {
	va_list args;
	va_start(args, arg_count);
	int sum = 0;
	for (size_t i = 0; i < arg_count; ++i) {
		sum += va_arg(args, int);
	}
	va_end(args);
	return sum;
}

int main(void) {
	int num[] = { 1, 2, 3, 4, 5 };
	printf("the sum of 1, 2, 3, 4, 5 is %d\n", sum(5, num[0], num[1], num[2], num[3], num[4]));

	return 0;
}
```
