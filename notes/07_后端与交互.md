## 后端

### 后端的作用

显示 matplotlib 图形。

### 配置后端的方式

- `matplotlibrc` 文件中 `rcParams["backend"]` 参数
- `MPLBACKEND` 环境变量
- 函数 `matplotlib.use()`

### 内置后端：静态后端

- 只能写入。

- 可以和用户界面结合。

## 图交互

- `pyplot.gcf`：获取当前的 figure，没有则创建
- `pyplot.gca`：获取当前的 axe，没有则创建
- `pyplot.close()`：关闭图
- 图交互模式通常与可视化用户界面相配合，如 qt、tk 等

![matplotlib 交互模式 API 表：ion/ioff/isinteractive/show/pause](attachments/matplotlib_交互模式API表.png)

## 交互模式参数

| 函数 | 作用 |
| --- | --- |
| `pyplot.ion` | 启用交互模式 |
| `pyplot.ioff` | 禁用交互模式 |
| `pyplot.isinteractive` | 返回是否在每次绘图命令后更新绘图 |
| `pyplot.show` | 显示所有打开的图形 |
| `pyplot.pause` | 运行 GUI 事件循环 `interval` 秒 |
