# 数组

## 注意事项

- 数组初始化的长度不能用变量表示，`const` 修饰的也不行，只能通过 `define`。
- 定义数组时必须初始化：不能写 `uint32_t arr[10];`，可以写 `uint32_t arr[10] = {}` 或 `uint32_t arr[10] = {0}`。
- C 语言的数组索引与 Python 不同，不可以使用负数。

```c
#include <stdio.h>
#include <stdint.h>
int main(void) {
	uint32_t arr[10] = {};
	uint32_t arr1[10] = {0};
	uint32_t two_dimension_arr[2][3] = {
		{1, 2, 3},
		{4, 5, 6},
	};
	// 隐式确定数组大小
	uint32_t two_dimension_arr1[][3] = {
		{1, 3, 4},
	};

}
```

数组与指针的结合用法（指针运算、比较、通过指针修改数组元素）见 [指针](03-变量与内存-指针.md)。
