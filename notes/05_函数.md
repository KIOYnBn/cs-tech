# 函数

本篇合并原 `函数.md` 与 `未命名.md` 中的函数条目（定义、参数、递归、lambda）。闭包与装饰器单独成篇，见 [`02_面向对象/02_闭包与装饰器.md`](../02_面向对象/02_闭包与装饰器.md)。

## 函数定义与调用

```python
def 函数名(参数列表):
    """文档字符串（可选，说明函数功能）"""
    函数体（实现功能的代码）
    [return 返回值]  # 可选，无 return 则默认返回 None

函数名(参数值列表)
```

## 参数类型

- **位置参数**
- **关键词参数**：`"参数名=值"` 传值
- **默认参数**：定义函数时给参数指定默认值
  - 默认参数必须放在**位置参数之后**（否则语法报错）。
- **可变位置参数**：`*args`
- **可变关键词参数**：`**kwargs`

### 多参数传入

- 位置传参：定义参数前加 `*`，如 `def people(*name)`，可接受任意个参数传入，并将其合并为元组。
- 关键字传参：定义函数前加 `**`。
- 同时存在多种传参时，位置传参要放在前面。

### 参数解包

- 列表解包 `*`：

```python
nums = [1, 2]
result1 = add(*nums)  # 等价于 add(1, 2)
```

- 字典解包 `**`：

```python
num_dict = {"a": 3, "b": 4}
result2 = add(**num_dict)  # 等价于 add(a=3, b=4)
```

## 函数递归

即在函数内部调用函数。缺点：占用内存较大。

## 匿名函数 lambda

```python
lambda 参数列表: 表达式
```

表达式结果就是返回值，无需写 `return`。常搭配 `filter`、`map` 使用：

```python
b = [1, 2, 3, 4, 5, 6, 7, 8, 9]

a = map(lambda x: x**2, b)     # 1, 4, 9, 16, 25 ...
a = filter(lambda x: x % 2 == 0, b)  # 2, 4, 6, 8
```
