# 头文件

## 内容

头文件中通常仅进行定义，比如函数只进行声明，具体实现在同名的 `.c` 文件中实现。

### 宏定义

- `#define 新名 旧名`
- 示例：`#define new_int int`

## 头文件加载

- 类型一：标准库 → `#include <头文件名称>`
- 类型二：本地库 → `#include "头文件名"`

## 常见头文件

| 头文件 | 说明 |
| --- | --- |
| `float.h` | 浮点数相关限制 |
| `inttypes.h` | 定义了 int 类型的格式转换宏 |
| `math.h` | 数学函数 |
| `stdint.h` | 定义了多种 int 类型 |
| `stdio.h` | 标准输入输出 |
| `time.h` | 时间函数 |
| `stdlib.h` | 通用工具，如 `srand` 用于初始化种子 |

## inttypes.h 用法：PRI 格式化输出

要点：

1. `%` 要与双引号贴着。
2. 双引号与 `PRI` 有空格隔开。

```c
#include <stdio.h>
#include <inttypes.h>
#include <stdint.h>

int main(void) {

	int32_t num1 = 32;
	int32_t num2 = 33;
	printf("the sum of %" PRId32 " and %" PRId32 " is %" PRId32 "", num1, num2, num1+num2);

	return 0;
}
```
