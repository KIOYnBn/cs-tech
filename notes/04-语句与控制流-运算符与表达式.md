# 运算符与表达式

## 除法与类型

在除法中，只要有一个数为浮点数，结果也会是浮点数。

## 并列条件（&&）

`&&` 可以并列多个元素。

- 例如 `for` 语句中一般只有一个判断条件，使用 `&&` 可以增加多个条件。
- 写法：`for(初始条件；判断条件1 && 判断条件2 && 判断条件3；内嵌步骤)`。
- 其他语句（如 `if`）也可以这么使用。

## 运算符优先级

![运算符优先级示例](attachments/运算符优先级示例.jpg)

- `! > && > ||`
- 示例：`!done && (count > MAX)`

## 短路求值

![逻辑运算短路求值](attachments/逻辑运算短路求值.jpg)

- 逻辑运算是自左向右进行的；如果左边的结果已经能够决定结果，就不会做右边的计算。
- `a==6 && b==1`（仅判断，不改变 `b`）。
- `a==6 && b+=1`（短路时 `b += 1` 不会执行）。
- 对于 `&&`，左边是 false 时就不做右边。
- 对于 `||`，左边是 true 时就不做右边。

## 取模范围

`x % n` 的结果为 `[0, n-1]` 中的一个数。
