# 常用内置模块与函数

本篇整理自原 `未命名.md` 草稿中的「内置函数」条目，涵盖随机数、数学函数与 Python 内置函数。

## 随机数：random

```python
import random
```

| 函数 | 作用 |
| --- | --- |
| `random.random()` | 返回一个 `[0.0, 1.0)` 区间内的随机浮点数 |
| `random.uniform(a, b)` | 返回一个 `[a, b]` 区间内的随机浮点数 |
| `random.randint(a, b)` | 返回一个 `[a, b]` 区间内的随机整数 |
| `random.randrange(start, stop[, step])` | 从指定范围内，按指定基数递增的集合中获取一个随机数 |
| `random.choice(sequence)` | 从一个非空序列中随机选取一个元素 |
| `random.sample(population, k)` | 从指定的序列中随机获取指定长度的片段，不会修改原序列 |
| `random.shuffle(x[, random])` | 用于将一个列表中的元素打乱顺序 |
| `random.seed(a=None, version=2)` | 初始化随机数生成器 |

`randrange` 示例：

```python
random.randrange(0, 100, 10)  # 可以生成 0 到 100 内的 10 的倍数
```

## 随机数：secrets（安全性更高）

```python
import secrets
```

| 函数 | 作用 |
| --- | --- |
| `secrets.randbelow(n)` | 返回一个 `[0, n)` 区间内的随机整数 |
| `secrets.randbits(k)` | 返回一个 k 比特长的随机整数 |
| `secrets.choice(sequence)` | 从一个非空序列中随机选取一个元素 |
| `secrets.choices(population, k)` | 从指定的序列中随机获取指定长度的片段，可能会有重复元素 |
| `secrets.shuffle(x)` | 用于将一个列表中的元素打乱顺序 |
| `secrets.token_urlsafe(nbytes)` | 生成一个适合在 URL 中使用的安全的随机令牌字符串 |

`token_urlsafe` 说明：返回的字符串由大小写字母和数字组成，长度为 `nbytes * 3 / 4`，大约 4/3 字节。

## 内置函数

| 函数 | 作用 |
| --- | --- |
| `abs()` | 绝对值函数 |
| `all(iter)` | 可迭代对象中元素布尔值都为 true 返回 true |
| `any(iter)` | 可迭代对象中元素布尔值只要有一个 true 就返回 true |
| `next(iter)` | 获得可迭代对象中下一个元素 |
| `filter(function, iter)` | 过滤器，满足 function 的 iter 中的元素会被返回 |
| `map(function, iter)` | 通过函数 function 对可迭代对象 iter 返回一个迭代器对象，可实现对 function 的多次变量传入 |

`map` 示例：

```python
def sum(a):
    b = 0
    for i in range(0, a):
        b += i
    return b

c = [1, 2, 3, 4, 5, 6]
b = list(map(sum, c))
print(b)  # [0, 1, 3, 5, 10, 15]（原文如此）
```

> 注：原文给出的输出 `[0, 1, 3, 5, 10, 15]` 与示例函数实际计算结果（`sum(4)=6`）存在差异，已按原文保留，供人工复核。
