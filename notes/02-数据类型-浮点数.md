# 浮点数

## 类型与默认行为

- `double`：默认类型，8 字节。
- `float`：4 字节。
- C 语言中默认的小数类型为 `double`；`float` 字面量需要加 `f` / `F` 后缀表明身份。

```c
#include <stdio.h>

int main(void) {
	double a = 10.34;
	float b = 10.34F;
	printf("double: %.2f, float: %.2f", a, b);
	printf("科学计数法:%e, 十六进制: %a", b, b);
	return 0;
}
```

## 范围与有效数字

| 类型 | 字长（位） | 范围 | 有效数字 |
| --- | --- | --- | --- |
| `float` | 32 | ±(1.20×10⁻³⁸ ~ 3.40×10³⁸)，0、±inf、nan | 7 |
| `double` | 64 | ±(2.2×10⁻³⁰⁸ ~ 1.79×10³⁰⁸)，0、±inf、nan | 15 |

## 浮点运算的精度

- 带小数点的字面量是 `double` 而非 `float`。
- `float` 变量需要用 `f` 或 `F` 后缀。
- `f1 == f2` 可能失败，应使用容差比较：`fabs(f1 - f2) < 1e-12`。

![浮点运算精度比较](attachments/浮点运算精度比较.png)

对应代码：

```c
float a, b, c;
a = 1.345f;
b = 1.123f;
c = a + b;
if (c == 2.468)
	printf("相等\n");
else
	printf("不相等！c=%.10f, 或%f\n", c, c);
```

## 浮点数的 printf 输出方式

1. `%f`：输出浮点数的默认格式说明符，未指定精度时输出六到七位十进制数字。
2. `%e`：以科学记数法输出，适用于非常大或非常小的数值。
3. `%E`：与 `%e` 类似，但指数部分为大写字母。
4. `%g`：自动选择 `%f` 或 `%e`/`%E`，取决于数值大小（在 `float` 范围内用 `%f`，超出则用科学计数法）。
5. `%G`：与 `%g` 类似，但指数部分为大写字母。
6. `%.nlf`：输出双精度浮点数并指定小数点后位数（原笔记写法），例如 `%.2lf` 保留两位小数。
