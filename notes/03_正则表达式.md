# 正则表达式

本篇合并原 `正则表达式.md` 与 `未命名.md` 中的正则条目。

## 元字符速查

| 元字符 | 含义 | 示例 |
| --- | --- | --- |
| `\d` | 匹配任意数字（0-9） | `\d{11}` 匹配 11 位数字 |
| `\D` | （原笔记仅列出符号，未注明含义） | — |
| `\w` | 匹配字母/数字/下划线 | `\w+` 匹配多个字母/数字 |
| `\W` | （原笔记仅列出符号，未注明含义） | — |
| `\s` | 匹配空白字符（空格/制表符，包括格式符） | `\s+` 匹配多个空白 |
| `\S` | （原笔记仅列出符号，未注明含义） | — |
| `.` | 表示任意字符，除换行符 | — |
| `@` | 匹配 @ 符号（普通字符） | `\w+@` 匹配「xxx@」 |
| `{n}` | 匹配前一个字符 n 次 | `\d{11}` 固定 11 位数字 |
| `{n,}` | 匹配前一个字符至少 n 次 | `\w{6,}` 至少 6 位字母/数字 |
| `^` | 匹配字符串开头（原笔记也称「取反符」） | `^1` 匹配以 1 开头的字符串 |
| `$` | 匹配字符串结尾 | `\d$` 匹配以数字结尾的字符串 |
| `\|` | 或逻辑 | — |
| `()` | 分组（提取匹配内容） | `(\d{11})` 提取 11 位数字 |

## 运算字符（量词）

| 符号 | 含义 |
| --- | --- |
| `+` | 匹配前一个字符出现 ≥1 次 |
| `*` | 匹配前一个字符出现任意次 |
| `?` | 匹配前一个字符出现 0-1 次 |

## 字符限定

- 内容限定：`[?]`，例如 `[a-z]`、`[a-zA-Z0-9]`、`[a-z]|[A-Z]`
- 次数限定：`{?}`，如 `\d{2}`、`\d{1,2}`、`\d{,2}`、`\d{0,}`

## 常用方法

| 方法 | 作用 | 适用场景 |
| --- | --- | --- |
| `re.compile()` | 编译正则表达式（重复使用时提升效率） | 多次匹配同一规则 |
| `re.findall()` | 提取所有匹配的内容，返回列表 | 提取所有手机号/邮箱 |
| `re.match()` | 匹配第一个符合规则的内容（原笔记：匹配第一个字符） | — |
| `re.search()` | 匹配第一个符合规则的内容，返回匹配对象；寻找字符串中第一次出现的目标字符 | 验证字符串是否包含目标 |
| `re.sub()` | 替换匹配的内容 | 脱敏处理（隐藏手机号中间4位） |
| `re.split()` | 分离字符 | `re.split('正则表达式【默认分组】', 字符串)` 或 `re.split('指定分隔符', 字符串)` |

## 查找与匹配示例

```python
# 不区分大小写：re.I
res = re.findall(r"A", "abc", re.I)
print(res)  # 'a'
```

## 分组

- `group`：分组匹配，`group(?)` 中的问号表示要调用的哪个组。

```python
a = '12-23-34'
print(re.match(r'(\d+)-(\d+)-(\d+)', a).group(1))     # '12'
print(re.match(r'(\d+)-(\d+)-(\d+)', a).group(1, 2))
```

- 分组调用（反向引用）：

```python
a = '<title>123asd<title>'
print(re.match(r'(\w*)(\w*)\1', a).group(2))  # '123asd'
```

- 分组命名：
  - 命名：`(?P<name>正则表达式)`
  - 使用：`(?P<name>)`（原笔记如此；实际 Python 语法为 `(?P=name)`，此处保留原文）

```python
a = '<title>123asd<title>'
print(re.match(r'(?P<tag>\w*)(\w*)\(?P<tag>)', a).group(2))  # '123asd'
```

- 分离字符 `groups`：

```python
c = '<title>sb123<title>'
b = re.compile(r'(<\w*>)(\w*)\1')
print(b.match(c).groups(0))  # ('<title>', 'sb123')
```

## 重用字符 re.compile

将正则表达式赋给变量，以变量代替正则表达式：

```python
c = '<title>sb123<title>'
b = re.compile(r'(<\w*>)(\w*)\1')
print(b.match(c).group(0))  # '<title>sb123<title>'
```

## 格式化字符（语法与 group 相似）

| 属性 | 说明 |
| --- | --- |
| `string` | 将结果变为字符串 |
| `span` | 结果所在位置区间 |
| `end` | 结果所在最后位置 |
| `start` | 结果所在最初位置 |

## 替换字符 re.sub

```python
re.sub('被替换字符', '替换字符', 字符串)
```
