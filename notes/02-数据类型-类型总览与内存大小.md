# 类型总览与内存大小

## 各类型占用内存大小（64 位）

| 类型 | 字节数 | 输入格式 | 输出格式 |
| --- | --- | --- | --- |
| `char` | 1 | `%d` | — |
| `short` | 2 | — | — |
| `int` | 4 | — | — |
| `long` | 4 | `%ld` | — |
| `long long` | 8 | — | — |
| `float` | 8（原笔记记载，见下方注意） | `%f` | `%f`、`%e`（科学计数法） |
| `double` | 16（原笔记记载，见下方注意） | `%lf` | `%f`、`%e` |
| 字符（定义方式：`'?'`） | — | `%c` | — |
| 字符串 | — | `%s` | — |
| 指针地址 | — | `*` | `%p` |

> **注意**：上表按原笔记保留，`float` 记为 8 字节、`double` 记为 16 字节；但 [浮点数](02-数据类型-浮点数.md) 笔记与配图记为 `float` 4 字节、`double` 8 字节。实际大小以 `sizeof` 在当前平台的结果为准。

**平台差异（整数类型）**：

| 平台 / 模型 | `int` 大小 | `long` 大小 | `long long` 大小 |
| --- | --- | --- | --- |
| Windows (LLP64) | 4 字节（32 位） | 4 字节（32 位） | 8 字节（64 位） |
| Linux/macOS (LP64) | 4 字节（32 位） | 8 字节（64 位） | 8 字节（64 位） |
| 16 位系统（罕见） | 2 字节（16 位） | 4 字节（32 位） | 8 字节（64 位） |

## sizeof 与 size_t

- `sizeof` 是一个**静态运算符**，其中无法做运算，可输出一个类型或变量占用的内存大小。
- 查看 `int` 所占字节：如 `int a = 1`，使用 `sizeof(a)`。
- `sizeof(int)` 的结果类型为 `size_t`（无符号整型），输出格式为 `%zu`。

```c
#include <stdio.h>

int main(void) {
	size_t int_size = sizeof(int);
	printf("the size of int :%zu", int_size);
	return 0;
}
```

也可针对变量查看：

```c
#include <stdio.h>

int main(void) {
	int num = 10;
	size_t sizeOfNum = sizeof(10);

	return 0;
}
```

- `size_t` 通常用来表示**内存中对象的大小**或**数组的长度**。

## 现代整型替换方案（stdint.h）

- 为便于多平台开发，VS 等环境建议使用 `stdint.h` 中的定宽类型，而不用 `short`、`int`、`long`。
- `int8_t` 表示 8 比特（1 字节），另有 `int16_t`、`uint8_t`、`uint32_t`、`int64_t` 等，均定义在 `stdint.h`。
- 格式化输出使用 `inttypes.h` 的 `PRId8`、`PRId16`、`PRId32` 等宏，而不是 `%d` 等。
  - 输出对应关系：`int8 → %hhd`，`int16 → %hd`，`uint32 → %u`。
- 大字面量后缀：大于 `uint32` 的数字需加相应大写字母，如 `uint32_t myUInt32 = 22222U`；`uint64_t` 用 `ULL`，`int64_t` 用 `LL`。
- 其他类型：`int_least16_t`、`int_fast16_t` 等。
- `INT32_MAX` 表示 `int32` 类型的最大值。

```c
#include <stdint.h>
typedef uint32_t u32;
int main(){
    u32 myVariable = 42;
    return 0
```

> 以上代码按原笔记保留，缺少分号与右花括号，使用时需自行补全。

## 无符号整型

- `unsigned` 是整型前缀，表示只有正数。
- 输出格式：`unsigned int → %u`，`unsigned short → %hu`，`unsigned long → %lu`。
- 以 `unsigned long` 定义的变量用 `%lu` 输出；二进制计算场景用 `%u` 表示。

## 浮点数说明

浮点数是一种表示实数的数据类型，包括整数、小数以及科学记数法表示的数。在计算机科学中，浮点数用于表示那些不能精确表示为整数的有理数，例如分数、小数和无限不循环小数（如 π 和 e）。详见 [浮点数](02-数据类型-浮点数.md)。
