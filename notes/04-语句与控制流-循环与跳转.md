# 循环与跳转

## while 循环

```c
int main(void) {
	while (表达式) {
		循环内容
	}
}
```

## do-while 语句

```c
int main(void) {
	do {
		循环内容
	} while (表达式);
}
```

## for 循环

```c
int main(void) {
	for (初始表达式; 条件表达式； 更新表达式) {
		循环内容
	}
}
```

## break 与 continue

![break与continue流程对比](attachments/break与continue流程对比.png)

- `break`：跳出当前循环体，直接结束循环。
- `continue`：跳过本次循环剩余部分，直接进入步进 / 下一轮判断。

## goto 跳出循环

`goto out`（`out` 为任意位置的标签）可跳转到指定位置，用于跳出多层循环。
