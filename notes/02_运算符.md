# 运算符

## 算术运算符

```
+, -, *, /, //, %, **
```

- `//`：整除，如 `a = 10 // 3 = 3`
- `**`：幂，如 `a = 2 ** 4 = 16`

## 赋值运算符

```
=, (算术运算符)=
```

如 `a = 1; b = 2; a += b; print(a)` → `3`

## 比较运算符

```
==, !=, >, <, >=, <=
```

## 逻辑运算符

```
and, or, not
```

- 逻辑运算输出为 `bool` 类型。

## 位运算符

- 位与 `&`
- 位或 `|`
- 异或 `^`（原笔记写作「异位与」）
- 位取反 `~`
- 左位移 `<<`
- 右位移 `>>`（原笔记此处残缺）

## 成员运算符

```
in, not in
```

## 身份运算符

```
is, is not
```
