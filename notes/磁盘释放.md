## 1. 标记wsl空闲块
1. wsl里执行
```bash
sudo fstrim -av
```
## 2. 关闭WSL
```bash
wsl --shutdown
```
## 3. 查找磁盘路径
1. 打开PowerShell
```bash
(Get-ChildItem -Path HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss | Where-Object { $_.GetValue("DistributionName") -eq 'Ubuntu' }).GetValue("BasePath") + "\ext4.vhdx"
```
## 4. 压缩
1. PowerShell打开diskpart
```Bash
diskpart
```
2. diskpart执行命令
```
select vdisk file="C:\xxx\ext4.vhdx"
attach vdisk readonly
compact vdisk
detach vdisk
exit
```
## 5. 自动回收
1. 关闭wsl后执行
```
wsl --manage Ubuntu --set-sparse true --allow-unsafe
```
