# Matplotlib 快速开始

本篇合并原 `matplotlib turorial/基本操作.md` 中的「使用前瞻」「figure 构造」「Axes 与 Axis 区别」「绘图示例」「封装绘制方法」「注解文本」条目。

## 使用前瞻

1. matplotlib 一般与 numpy 联合使用，因为 matplotlib 支持 np 的 array 矩阵类型，对于大批量数据，需要转化为 array 类型使用。
2. 导入 matplotlib：`import matplotlib.pyplot as plt`
3. 文本中支持 latex 语法，使用方法和 markdown 一样。

## Axes 和 Axis 的区别

| 特征 | Axes | Axis |
| --- | --- | --- |
| 类型 | 绘图区域 | 坐标轴 |
| 作用 | 设置坐标轴刻度和限制、标签、标题 | 刻度和刻度标签 |

## 绘图示例

> 隐式风格和显式风格的最大区别在于是否显式化赋值 `ax`。

### 显式风格

```python
x = np.linspace(0, 2, 100)  # Sample data.

# Note that even in the OO-style, we use `.pyplot.figure` to create the Figure.
fig, ax = plt.subplots(figsize=(5, 2.7), layout='constrained')
ax.plot(x, x, label='linear')  # Plot some data on the Axes.
ax.plot(x, x**2, label='quadratic')  # Plot more data on the Axes...
ax.plot(x, x**3, label='cubic')  # ... and some more.
ax.set_xlabel('x label')  # Add an x-label to the Axes.
ax.set_ylabel('y label')  # Add a y-label to the Axes.
ax.set_title("Simple Plot")  # Add a title to the Axes.
ax.legend()  # Add a legend.
```

### 隐式风格

```python
x = np.linspace(0, 2, 100)  # Sample data.

plt.figure(figsize=(5, 2.7), layout='constrained')
plt.plot(x, x, label='linear')  # Plot some data on the (implicit) Axes.
plt.plot(x, x**2, label='quadratic')  # etc.
plt.plot(x, x**3, label='cubic')
plt.xlabel('x label')
plt.ylabel('y label')
plt.title("Simple Plot")
plt.legend()
```

## 封装 matplotlib 绘制方法

示例：

```python
def my_plotter(ax, data1, data2, param_dict):
    """
    A helper function to make a graph.
    """
    out = ax.plot(data1, data2, **param_dict)
    return out

data1, data2, data3, data4 = np.random.randn(4, 100)  # make 4 random data sets
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(5, 2.7))
my_plotter(ax1, data1, data2, {'marker': 'x'})
my_plotter(ax2, data3, data4, {'marker': 'o'})
```

## 注解文本（annotate）

- `annotate` 参数：
  - `text`：文本内容，支持 latex
  - 坐标点：`(x, y)`
  - 坐标系 `transform`
    - `transData`：默认，数据坐标系，与数据范围有关
    - `transAxes`：子图坐标系
    - `transFigure`：画布坐标系
  - 水平对齐 `ha`：`left`、`center`、`right`
  - 垂直对齐 `va`
  - 字体大小 `fontsize`
  - 其他参数参见 [`03_文本与注解.md`](03_文本与注解.md)

```python
fig, ax = plt.subplots(figsize=(5, 2.7))

t = np.arange(0.0, 5.0, 0.01)
s = np.cos(2 * np.pi * t)
line, = ax.plot(t, s, lw=2)

ax.annotate('local max', xy=(2, 1), xytext=(3, 1.5),
            arrowprops=dict(facecolor='black', shrink=0.05))

ax.set_ylim(-2, 2)
```

> 注：`annotate` 的完整参数（bbox、coords、arrowstyle、connectionstyle）详见 [`03_文本与注解.md`](03_文本与注解.md)。
