# 条件判断

## if 语句

```c
#include <stdio.h>
int main(void) {
	int number = 10;
	if (number >= 10) {
		puts("number >= 10");
	}
	else if (0<=number<10) {
		puts("0 <number < 10");
	}
	else {
		puts("number为负数");
	}
	return 0;
}
```

> **注意**：原笔记中的 `else if (0<=number<10)` 写法在 C 中不能表达区间判断，应写成 `else if (number >= 0 && number < 10)`。

## if 语句的常见语法错误

使用模板：

```c
if (条件1) {
}
else if (条件2) {
}
else {
}
```

注意点：只有 `else` 时，其后不能加括号，否则会显示缺少 `;` 的提示；但如果按照提示加入分号，会发现这个 `else` 条件语句没有发挥作用。即，如果需要在 `else` 后加入判断条件，请写成 `else if`。

## 简化 if 语句（三目运算符）

```c
int main(void) {
	int score = 80;
	char grade;
	grade = (score > 90 ) ? 'A':
		(score >= 80) ? 'B':
		(score >= 70) ? 'C': 'D';
	return 0;
}
```

## switch-case 语句

需要注意的是，`switch` 里的 `(number)` 必须是整型。

```c
int main(void) {
	int number = 8;
	switch (number ) {
		case 1:
			puts("one");
			break;
		case 2:
			puts("two");
			break;
		default:
			puts("over two");
			break;
	}
	return 0;
}
```
