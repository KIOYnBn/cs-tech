# 文本与注解

本篇合并原 `matplotlib turorial/文本.md` 与 `matplotlib turorial/注解.md`，并收录 `基本操作.md` 中的 annotate 参数（后者亦见 [`01_快速开始.md`](01_快速开始.md)）。

## 常见文本及 API

| 隐式 API | 显式 API | 功能 |
| --- | --- | --- |
| `text` | `text` | axes 任意位置添加文本 |
| `annotate` | `annotate` | Axes 任意位置添加注释，可带有箭头 |
| `xlabel` | `set_xlabel` | x 轴标签 |
| `ylabel` | `set_ylabel` | y 轴标签 |
| `title` | `set_title` | Axes 的标题 |
| `figtext` | `text` | Figure 任意位置添加文本 |
| `suptitle` | `suptitle` | 为 Figure 添加标题 |

## 特定参数

### x/y 轴标签

- `labelpad`: int
- `fontsize`
- `fontweight`（原笔记写作 `fongweight`）
- `fontproperties`: font
- 添加 `\n` 可以实现换行

### 标题

- 大致与标签相同
- `loc`：改变位置和对齐方式

## annotate 参数

| 参数 | 说明 |
| --- | --- |
| `text` | str，文本内容，支持 latex |
| `xy` | 数据位置，坐标点 `(x, y)` |
| `xytext` | 文本位置 |
| `arrowprops` | 箭头属性设置 |
| `va` | 垂直方向位置 |
| `ha` | 水平方向位置 |
| `textcoords` | 文本的坐标系；相对文本的偏移量 |
| `xycoords` | 数据点的坐标系；相对数据点偏移量 |
| `bbox` | 画框 |

### arrowprops 参数

| 参数 | 说明 |
| --- | --- |
| `width` | 箭头宽度 |
| `frac` | 头部所占百分比 |
| `headwidth` | 头部的尾部宽度 |
| `shrink` | 箭头尾部和头部相对目标点偏移量 |
| kwargs | polygon 参数（原笔记写作 pollygon） |

- 自定义箭头：`dict(arrowstyle, connectionstyle)`

### bbox（画框）

- 访问：`get_bbox_patch`
- 属性设置：`set_boxstyle`
