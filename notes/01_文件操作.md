# 文件操作

本篇合并原 `文件操作.md` 与 `未命名.md` 中的文件交互条目。

## 文件打开与关闭

- 文件打开：`open`
  - `file_object = open(file, mode='r', encoding=None)`
  - 参数：
    - `file_path`: str
    - `mode`: str
    - `encoding`: utf-8 / gbk
      - 中文文件必须要 utf-8
- 文件关闭：`close`
  - `file_object.close`（原笔记如此，实际调用应为 `file_object.close()`）

```python
variate = open(filename, 'r', encoding='utf-8')
```

### 文件打开方式（mode）

| 模式 | 说明 | 补充 |
| --- | --- | --- |
| `'r'` | 只读 | 文件必须存在；文件指针在开头，文件不存在报错 |
| `'w'` | 只写 | 清空原有内容；文件不存在则创建，存在则内容覆盖 |
| `'a'` | 追加 | 文件不存在创建，存在则在最后追写内容 |
| `'rb'` | 二进制只读 | 无需指定 encoding，读取非文本文件（如图片） |
| `'wb'` | 二进制只写 | 覆盖写二进制文件 |
| `'ab'` | 二进制追加 | — |
| `'r+'` | 读写 | 会覆盖原有内容 |
| `'+'` | 多功能组合 | 可与 w/r/a 一起使用 |

## 读取

| 方法 | 说明 |
| --- | --- |
| `read(size:int)` | size 为字符串数或字节数，默认为读取全部；给定 size 则读取给定字符或字节 |
| `readline` | 逐行读取，包括换行符。文件末尾为空字符串 |
| `readlines` | 读取所有行，返回列表 |
| for 循环 | `for index, line in enumerate(file_object):` |

```python
content = file_object.read(size)   # 原文此处缺右括号
```

## 写入

- `write(str)`
- `writelines(iterable)`：将内容全部为字符串的列表写入

## 文件指针

- `tell()`：返回当前文件指针位置（字节）
- `seek(offset, whence)`：移动指针
  - `offset`: int，正数为向后移动，负数为向前移动
  - `whence`：
    - `0`：文件开头
    - `1`：当前位置
    - `2`：文件末尾
  - `seek(offset)`：改变当前文件操作指针的位置；英文占一个字节，中文 gbk 编码占两个字节，utf-8 编码占三个字节

## 关闭文件与 with 语句

```python
close()
```

`with` 语句结构：

```python
with open() as f:
    pass
```

作用：在处理文件时，无论是否异常，都在 `with` 语句结束后关闭文件，无需手动关闭。

## os 库 / 操作系统交互

### 路径与目录操作

| 函数 | 作用 |
| --- | --- |
| `os.mkdir(path)` | 创建一级目录 |
| `os.makedirs(path)`（原笔记写作 `os.mkdirs`） | 创建多级目录 |
| `os.listdir(path)` | 返回所有文件和子目录；获取 path 下的文件和路径信息，默认当下 |
| `os.walk` | 返回目录下所有目录与子目录，返回三元组（当前路径，子目录路径，文件列表）；遍历 path，结果为元组 |
| `os.rmdir(path)` | 删除单一级目录；删除 path 下空目录 |
| `os.removedirs(path)`（原笔记写作 `os.rmdirs`） | 删除多级目录 |
| `os.getcwd()` | 获取当前工作路径 |
| `os.chdir(path)` | 把 path 设置为当前目录 |

### 文件与判断操作

| 函数 | 作用 |
| --- | --- |
| `os.rename(old_name, new_name)` | 重命名（原笔记写作「重命令」） |
| `os.remove(path)` | 删除文件，不删除目录 |
| `os.path.exists(path)` | 判断文件是否存在 |
| `os.path.isfile(path)` | 判断是否文件 |
| `os.path.isdir(path)` | 判断是否目录 |
| `os.path.join(path1, path2)` | 路径拼接 |
| `os.stat(path)` | 获取 path 的文件信息 |
| `os.startfile(path)` | 启动 path 文件 |
