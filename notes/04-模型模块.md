## 1. 自注意力机制（SelfAttention）

**规范实现**（返回注意力权重，便于可视化与分析）：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Optional, Tuple

class SelfAttention(nn.Module):
    """Multi-head self-attention mechanism"""
    def __init__(self, hid_dim: int, n_heads: int, dropout: float, device: torch.device):
        super().__init__()
        self.hid_dim = hid_dim
        self.n_heads = n_heads
        assert hid_dim % n_heads == 0, "Hidden dimension must be divisible by number of heads"
        self.w_q = nn.Linear(hid_dim, hid_dim)
        self.w_k = nn.Linear(hid_dim, hid_dim)
        self.w_v = nn.Linear(hid_dim, hid_dim)
        self.fc = nn.Linear(hid_dim, hid_dim)
        self.do = nn.Dropout(dropout)
        self.scale = torch.sqrt(torch.FloatTensor([hid_dim // n_heads])).to(device)

    def forward(self, query: torch.Tensor, key: torch.Tensor, value: torch.Tensor,
                mask: Optional[torch.Tensor] = None) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Args:
            query / key / value: [batch_size, seq_len, hid_dim]
            mask: optional attention mask
        Returns:
            output: [batch_size, seq_len, hid_dim]
            attention: [batch_size, n_heads, seq_len, seq_len]
        """
        batch_size = query.shape[0]
        Q = self.__reshape__(self.w_q(query), batch_size)
        K = self.__reshape__(self.w_k(key), batch_size)
        V = self.__reshape__(self.w_v(value), batch_size)
        energy = torch.matmul(Q, K.permute(0, 1, 3, 2)) / self.scale
        if mask is not None:
            energy = energy.masked_fill(mask == 0, -1e10)
        attention = self.do(F.softmax(energy, dim=-1))
        x = torch.matmul(attention, V)
        x = x.permute(0, 2, 1, 3).contiguous()
        x = x.view(batch_size, -1, self.n_heads * (self.hid_dim // self.n_heads))
        x = self.fc(x)
        return x, attention

    def __reshape__(self, x: torch.Tensor, batch_size: int):
        return x.view(batch_size, -1, self.n_heads, self.hid_dim // self.n_heads).permute(0, 2, 1, 3)
```

- 另一种写法（见完整模型代码）只返回输出 `x`，用 `Q @ K.permute(0,1,3,2)` 代替 `torch.matmul`，并用 `energy.masked_fill(mask == 0, -1e10)` 处理掩码；`contiguous()` 用于使元素内存分布均匀、提高计算效率。故调用时须按实现决定解包一个还是两个返回值。

### Flash Attention vs 原始 Attention

```python
import torch
import torch.nn.functional as F
import time

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
dtype = torch.float16

batch_size, num_heads, seq_len, head_dim = 1, 8, 2048, 64  # seq_len 可改 1024/4096
torch.manual_seed(42)
query = torch.randn(batch_size, num_heads, seq_len, head_dim, device=device, dtype=dtype)
key   = torch.randn(batch_size, num_heads, seq_len, head_dim, device=device, dtype=dtype)
value = torch.randn(batch_size, num_heads, seq_len, head_dim, device=device, dtype=dtype)

# 1. 手动普通 Attention（O(N^2) 显存）
def manual_attention(q, k, v, causal=False):
    scale = q.size(-1) ** -0.5
    attn_weights = (q @ k.transpose(-2, -1)) * scale
    if causal:
        L, S = q.size(-2), k.size(-2)
        mask = torch.ones(L, S, dtype=torch.bool, device=q.device).tril()
        attn_weights.masked_fill_(mask.logical_not(), float("-inf"))
    return torch.softmax(attn_weights, dim=-1) @ v

# 2. 强制数学后端的 SDPA
def math_attention(q, k, v, causal=False):
    with torch.backends.cuda.sdp_kernel(enable_flash=False, enable_math=True, enable_mem_efficient=False):
        return F.scaled_dot_product_attention(q, k, v, is_causal=causal)

# 3. 自动 SDPA（实际跑 FlashAttention / Memory-Efficient）
def auto_sdpa(q, k, v, causal=False):
    return F.scaled_dot_product_attention(q, k, v, is_causal=causal)

def benchmark(func, *args, warmup=3, repeat=10, name=""):
    for _ in range(warmup):
        func(*args)
    torch.cuda.synchronize()
    start = time.time()
    for _ in range(repeat):
        func(*args)
    torch.cuda.synchronize()
    elapsed = (time.time() - start) / repeat
    torch.cuda.reset_peak_memory_stats()
    torch.cuda.empty_cache()
    with torch.no_grad():
        out = func(*args)
    peak_mem = torch.cuda.max_memory_allocated() / 1024**3
    print(f"{name:40s} | time: {elapsed*1000:7.2f} ms | peak memory: {peak_mem:.2f} GB")
    return out, elapsed, peak_mem

out_manual, _, _ = benchmark(manual_attention, query, key, value, True, name="Manual (naive)")
out_math, _, _   = benchmark(math_attention, query, key, value, True, name="SDPA math backend (naive)")
out_auto, _, _   = benchmark(auto_sdpa, query, key, value, True, name="SDPA auto (FlashAttn etc.)")
print(f"Max diff manual vs math = {(out_manual - out_math).abs().max().item():.6f}")
print(f"Max diff manual vs auto = {(out_manual - out_auto).abs().max().item():.6f}")
```

**实测结果**（RTX 4060 Laptop GPU，float16，seq_len=2048，causal）：

| 实现 | 时间 | 峰值显存 |
| --- | --- | --- |
| Manual (naive) | 2.52 ms | 0.14 GB |
| SDPA math backend (naive) | 8.15 ms | 0.33 GB |
| SDPA auto（FlashAttn 等） | 0.30 ms | 0.02 GB |

最大误差 manual vs math = 0.001953；manual vs auto = 0.001953。

## 2. Padding 与 Mask

- **mask 分类**：padding mask 与 sequence mask。
  - **Padding mask**：配合 padding 使用，将用于整合矩阵形状的标记设置为无穷大，注意力计算时忽略标记，避免其影响判断。
  - **Sequence mask**：用于掩盖未来的关键信息。

### 2.2 在注意力中屏蔽 padding

```python
class Attention(nn.Module):
    def __init__(self, dim, num_heads=8, qkv_bias=False, qk_scale=None, attn_drop=0., proj_drop=0.):
        super().__init__()
        self.num_heads = num_heads
        head_dim = dim // num_heads
        self.scale = qk_scale or head_dim ** -0.5
        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

    def forward(self, x, mask=None):
        B, N, C = x.shape
        qkv = self.qkv(x).reshape(B, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]
        attn = (q @ k.transpose(-2, -1)) * self.scale
        # mask 对应真实值为 0、填充符为 1，将 attn 中所有 1 置为 -inf
        if mask is not None:
            attn = attn.masked_fill(mask.unsqueeze(1).unsqueeze(2) == 1, float('-inf'))
        attn = self.attn_drop(attn.softmax(dim=-1))
        x = (attn @ v).transpose(1, 2).reshape(B, N, C)
        return self.proj_drop(self.proj(x))
```

## 3. GLU 门控线性单元

GLU（Gate Linear Unit，门控线性单元）：

$$\text{GLU}(X) = X_1 \odot \sigma(X_2)$$

- $X$：输入张量，通道维度长度为 $2d$。
- $X_1, X_2$：沿通道维度均分得到的两个子张量，维度 $d$；$X_1$ 为主特征分量，$X_2$ 为特征权重。
- $\sigma(x) = \dfrac{1}{1+e^{-x}}$；$\odot$ 为逐元素相乘。

```python
import torch.nn.functional as F
F.glu(x, dim=1)   # 通道维均分；另有实现使用 dim=-1
```

**变体**：

- ReGLU：将 Sigmoid 换成 ReLU，$\text{ReGLU} = X_1 \odot \text{ReLU}(X_2)$。
- SwiGLU：结合 Swish 激活，广泛用于大语言模型。

应用示例见 [Conv1D+GLU 编码器](05-大模型与Transformer.md#4-conv1dglu-编码器)。

## 4. 前馈网络

### 4.1 普通前馈网络（FFN）

结构：**线性升维 → 激活 → 线性降维**。

$$
H = \text{ReLU}(XW_1 + b_1),\quad Y = HW_2 + b_2
$$

- $X\in\mathbb{R}^{B\times D}$：单样本二维特征；$W_1\in\mathbb{R}^{D\times pf\_dim}$ 升维；$W_2\in\mathbb{R}^{pf\_dim\times D}$ 降维。
- 核心特性：基于整行特征全局映射，权重与「位置」无关。

```python
class NormalFFN(nn.Module):
    def __init__(self, hid_dim, pf_dim, dropout):
        super().__init__()
        self.fc1 = nn.Linear(hid_dim, pf_dim)
        self.fc2 = nn.Linear(pf_dim, hid_dim)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        x = self.dropout(F.relu(self.fc1(x)))
        return self.fc2(x)
```

### 4.2 位置前馈网络（PWFFN）

特点：把 linear 换成 `Conv1d`（1×1 卷积核），每个特征单独变化，彼此之间没有关联。

```python
class PositionwiseFeedforward(nn.Module):
    """Position-wise feedforward network."""
    def __init__(self, hid_dim: int, pf_dim: int, dropout: float):
        super().__init__()
        self.fc_1 = nn.Conv1d(hid_dim, pf_dim, 1)
        self.fc_2 = nn.Conv1d(pf_dim, hid_dim, 1)
        self.do = nn.Dropout(dropout)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = x.permute(0, 2, 1)                  # [B, D, L]
        x = self.do(F.relu(self.fc_1(x)))       # [B, pf_dim, L]
        x = self.fc_2(x)
        return x.permute(0, 2, 1)
```

## 5. 池化

### 5.1 注意力加权池化

1. 对每个位置的特征向量求二范数，衡量该位置特征的重要性；
2. 通过 softmax 将范数转化为全局权重，权重越大代表该局部位置越关键；
3. 加权累加所有位置特征，将**序列特征**压缩为**全局样本特征**，适配分类任务。

> 优点：相比平均池化、最大池化，能自适应突出关键结合位点特征，提升预测精度。

```python
norm = torch.norm(trg, dim=2)                    # [batch, seq_len]
norm = F.softmax(norm, dim=1)
sum_features = torch.zeros((trg.shape[0], self.hid_dim)).to(self.device)
for i in range(norm.shape[0]):
    for j in range(norm.shape[1]):
        sum_features[i, :] += trg[i, j, :] * norm[i, j]
```

## 6. 归一化与残差缩放

### 6.1 LayerNorm（层归一化）

作用：**分布矫正**，对 D 维特征做均值归零、方差归一：

$$\text{LN}(x) = \frac{x-\mu}{\sigma}\cdot\gamma + \beta$$

只改变数值分布，**不压缩、不删除任何维度信息**；用于**稳定训练**，让深层网络收敛更快。

```python
self.ln = nn.LayerNorm(hid_dim)
```

### 6.2 L2 范数（Norm）

L2 范数（欧氏距离）在深度学习中衡量一个特征向量的整体「信息量大小、活跃度强弱」：

$$\|x\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_D^2}$$

- 结果是一个标量，恒非负。
- 代码：`torch.norm(trg, dim=2)`（变量名原文写作 `dim_inidex`，疑为笔误）。
- 应用见 [注意力加权池化](#51-注意力加权池化)。

### 6.3 残差缩放

$$F_{res} = (F_{glu} + X_{in})\cdot\frac{1}{\sqrt{2}}$$

设两个独立同分布特征方差均为 $\sigma^2$，则 $\text{Var}(a+b) = 2\sigma^2$，乘以 $1/\sqrt{2}$ 后恢复为 $\sigma^2$。

**作用**：抵消相加带来的方差膨胀，稳定数值分布。应用见 [Conv1D+GLU 编码器](05-大模型与Transformer.md#4-conv1dglu-编码器)。

## 7. 卷积层

**使用建议**：

1. 卷积核小、多层卷积层的效果更好。
2. 可同时使用不同卷积核并行计算，提高特征提取性能：多尺度卷积并行、动态卷积、空洞卷积、卷积核融合、分组卷积。
3. 保持形状可用 padding（在输入周围添加额外的行/列，控制形状减少量，实现深度卷积）；步长可成倍减少输出形状。

输出形状（向下取整）：

$$\left\lfloor\frac{n_h - k_h + 2p_h}{s_h} + 1\right\rfloor \times \left\lfloor\frac{n_w - k_w + 2p_w}{s_w} + 1\right\rfloor$$

```python
nn.Conv2d(1, 1, kernel_size=3, padding=1, stride=2)
```

| 参数 | 维度变化 |
| --- | --- |
| input | $n \times n$ |
| w | $k \times k$ |
| output | $(n-k+1)\times(n-k+1)$ |
