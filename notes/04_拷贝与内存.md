# 拷贝与内存

本篇整理自原 `未命名.md` 草稿中的「拷贝的分类」条目。

## 前提说明

> 注：只有可变对象才有以下分类，不可变对象的各种拷贝下的值和地址都一样。

## 复制（赋值）

```python
a = b
```

- 两个变量的指针地址相同，改变 `a`，`b` 也改变。

## 浅拷贝

```python
b = copy.copy(a)
```

- 会引用 `a` 的外围元素的指针。
- 当 `a` 中增加新的元素（开辟了新的空间）时，对 `b` 无影响。
- 但如果是在 `a` 中已有的空间或指针增加新的元素时，`b` 会改变。例如 `a` 中已有一个列表元素，这个列表元素中新增元素，`b` 中会相应地增加这个元素。

示例：

```python
import copy
a = [1, [6]]
b = copy.copy(a)
a.append(213)
print(b)       # 结果：[1, [6]]

a[1].append(213)
print(a, b)    # 结果：[1, [6, 213], 213]，[1, [6, 213]]
```

## 深拷贝

- 结果会新开辟空间，与原来的变量毫无关系。

```python
copy.deepcopy()
```
