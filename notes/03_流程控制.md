# 流程控制

本篇合并原 `语句.md` 与 `未命名.md` 中的条件语句条目。

## 条件控制语句

### if 语句

```python
if 条件表达式:
    满足条件时执行的代码块（注意缩进）

if 条件表达式:
    满足条件时执行的代码块
else:
    不满足条件时执行的代码块

if 条件1:
    满足条件1执行的代码块
elif 条件2:
    不满足条件1但满足条件2执行的代码块
...（可多个 elif）
else:
    所有条件都不满足时执行的代码块
```

### 三元表达式

```python
结果1 if 条件 else 结果2
```

### match 语句（相当于 switch）

```python
match value:
    case 1:
        内容
    case 2:
        内容
```

> 注：`match` 条目来自原 `未命名.md`，原文写作 `case1` / `case2`，此处按 Python 语法规范补空格并保留原意。

## 循环语句

### for 语句

```python
for 变量 in 可迭代对象（列表/字符串/range 等）:
    每次循环执行的代码块
```

### while 循环

```python
while 条件表达式:
    条件满足时执行的代码块
    （需设置终止条件，避免死循环）
```

## 循环控制语句

- `break`
- `continue`
- `pass`
