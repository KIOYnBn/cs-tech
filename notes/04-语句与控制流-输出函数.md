# 输出函数

## printf：格式转换

格式串结构：`%[flags][width][.precision][size]type`

### flags

| flag | 含义 |
| --- | --- |
| `-` | 左对齐（如 `%10d` 右对齐，`%-10d` 左对齐） |
| `+` | 显示符号（如正负号） |
| `0` | 空白位补 0 |
| `#` | 修饰八进制、十六进制（显示进制前缀） |

> 浮点数的 `%f`、`%e`、`%E`、`%g`、`%G`、`%.nlf` 等格式见 [浮点数](02-数据类型-浮点数.md)。

## puts

用于输出字符串。

```c
int main(void) {
	puts("hello");
	return 0;
}
```
