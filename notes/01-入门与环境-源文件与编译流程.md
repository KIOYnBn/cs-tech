# 源文件与编译流程

## C 源文件基本约定

1. C 语言源文件后缀为 `.c`，且 `c` 为小写。
2. 文件名长度有限制：
   - MS-DOS 基本文件名不能超过 8 个字符；
   - 部分 UNIX 系统（含扩展名）不能超过 14 个字符；
   - 其他系统一般不超过 255 个字符。
3. 让程序执行后保留执行窗口：在 `return` 前加 `getchar()`，按 Enter 退出；若程序本身需要 Enter 激活，可用两次 `getchar()`。

## x86 与 x64

- x86：32 位 CPU。
- x64：64 位 CPU。

## 命令行参数

`main` 可接收命令行参数：`argc` 为参数个数，`argv[0]` 为程序名，`argv[1..argc-1]` 为实际参数。

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char* argv[]) {
	printf("The project name is: %s\n", argv[0]);
	printf("The number of arguments is: %d\n", argc);
	for (size_t i = 0; i < argc; i++) {
		printf("Argument %zu: %s\n", i, argv[i]);
	}
	system("pause");

	return 0;
}
```
