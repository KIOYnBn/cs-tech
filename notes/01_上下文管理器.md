# 上下文管理器

## 基础知识

- 上下文管理器需要包含 `__enter__` 和 `__exit__` 两个基本函数。
- `with` 进入时，调用 `__enter__`；结束时，调用 `__exit__`。
- `__exit__` 参数解析：
  - `exc_type`：异常类型
  - `exc`：异常对象（信息）
  - `tb`：traceback 调用栈信息（原笔记写作「欣喜」）
  - 返回 `True`，则会抑制异常；`False`，异常继续抛出。

## 自定义 with 上下文管理器

```python
import time
class Timer:
    def __enter__(self):
        self.start = time.perf_counter()
        return self
    def __exit__(self, exc_type, exc, tb):
        self.end = time.perf_counter()
        self.elapsed = self.end - self.start
        print(f"耗时: {self.elapsed:.4f}s")
        return False
def slow_function():
    time.sleep(1)

with Timer() as t:
    slow_function()
```

## contextmanager 便携用法

示例：

```python
from contextlib import contextmanager
import time

@contextmanager
def timer()
    start_time = time.perf_counter()
    try:
        # 相当于 enter
        yield
    finally:
        # 相当于 exit
        end_time = time.perf_count()  # 原文如此（应为 perf_counter）
        print(f'Time:{end_time-start_time:.4f}')

with timer():
    text:str = ''
    for i in range(100):
        text += str(i)
```

> 注：原笔记中 `def timer()` 缺冒号、`time.perf_count()` 拼写有误，均按原文保留，便于人工复核。

## with 语句（文件场景）

结构：

```python
with open() as f:
    pass
```

作用：在处理文件时，无论是否异常，都在 `with` 语句结束后关闭文件，无需手动关闭。参见 [`04_文件与数据/01_文件操作.md`](../04_文件与数据/01_文件操作.md)。
